    OptionaltimeZone

    timeZone?: string

    Zone the instrument's clock was set to, as an IANA name ('Europe/Zurich'), a fixed offset ('+01:00') or 'UTC'.

    An SPC file records the wall clock the operator saw and never its offset, so without this option a decoded date names no instant: it is read as the reader's own local time, which differs between a lab machine and a UTC server. Naming the lab's zone makes every date an instant that is the same everywhere. The unix layout is already an instant and is never shifted.

    Default

    undefined
